Wichtig für GitHub Pages

GitHub Pages liefert Dateien aus, kann aber selbst keine Datenbankänderungen speichern. Dieses Paket funktioniert deshalb sofort im lokalen Browser-Modus. Für einen echten Geschäftsführer-Login auf mehreren Geräten braucht es später ein Backend (z. B. Supabase/Firebase). Details stehen in der README.
